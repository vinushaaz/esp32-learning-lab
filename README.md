# ESP32 Learning Lab ⚡

A hands-on embedded systems learning repository documenting my journey with ESP32, firmware development, hardware interfacing, communication protocols, and IoT.

## 🎯 Purpose

This repository serves as my practical engineering laboratory. Each experiment focuses on understanding fundamental concepts, implementing them through code, testing hardware behaviour, and documenting the learning process.

## 🛠️ Development Tools

- ESP32 Development Board
- Visual Studio Code
- ESP-IDF
- PlatformIO
- C / C++
- Git and GitHub
**Learning by building. Engineering by experimenting.**
